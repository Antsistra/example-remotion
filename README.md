# Umah Tani Promo (Remotion)

30-second vertical promo (1080x1920, 30 fps, 900 frames) for Umah Tani.
The app UI is rebuilt as React/CSS components; no screenshots are used.

## Usage

- Install: `npm install`
- Preview in Remotion Studio: `npm run dev`
- Render: `npm run render` (writes `out/umah-tani-promo.mp4`)

Composition id: `UmahTaniPromo`. Timing lives in `src/timeline.ts`, palette in `src/theme.ts`.

Note: the logo is redrawn as SVG and the product art is vector, reconstructed without the original assets.
